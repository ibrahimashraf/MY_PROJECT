# Canonical Repository Scope 
 
Status: Preflight scope for the private INTEGIN repository. 
 
## Include 
Go source, migrations, contracts, field_app source, ai_service source, scripts, checked-in tests, credential-free examples, and source-local documentation. 
 
## Exclude 
Private material, real environment files, local runtime data, Docker volumes, evidence, protected fixtures, build output, dependency caches, virtual environments, IDE state, logs, and user-owned files. 
 
## Workspace Boundary 
The separate INTEGIN-source snapshot, private directory, operations runtime records, migration backups, archives, and user-owned PDF are outside this repository baseline unless explicitly brought in through a later reviewed change.
