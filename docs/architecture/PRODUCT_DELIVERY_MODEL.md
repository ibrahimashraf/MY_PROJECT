# INTEGIN Product Delivery Model 
 
Status: Proposed pending product-owner confirmation. 
 
## Product Surfaces 
- INTEGIN Field: native Flutter app for Android and iOS, with optional Windows support for specialist field laptops. 
- INTEGIN Operator: responsive web application that may be installed as a PWA shortcut for authoring, assignment, review, reporting, and governance. 
 
## Windows Pilot Boundary 
The completed Windows executable is a controlled native field-app verification target, not a Windows-only delivery decision and not a replacement for the operator web application. 
 
## Shared Work Packages 
The operator and field surfaces share approved versioned work-package schemas. The native app caches assigned packages and renders them offline without embedding the operator website or using WebView2 as the trusted field path.
