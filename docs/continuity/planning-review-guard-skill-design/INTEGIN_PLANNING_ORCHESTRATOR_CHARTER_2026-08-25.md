# INTEGIN Planning Orchestrator Charter

## Identity

Create a new locally owned skill named **`integin-planning-orchestrator`**. It combines the active local planning-with-files workflow, its complete local capability pack, and the explicit PC-bridge/host-automation protocols into one independently written package.

The existing `planning-with-files` package remains unchanged as a rollback-compatible predecessor. The new package is not an online-source fork, release, or installation.

## Clean-room boundary

The prior online audit remains evidence only. Do not copy external code, scripts, templates, prompts, frontmatter, hooks, version identity, or installation behavior. For every audited source role, include either an independently written local equivalent, an explicit host-integration module, or a visible non-activatable requirement. No source role may disappear from the ledger.
