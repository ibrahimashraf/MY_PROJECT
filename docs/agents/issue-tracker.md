## Reading

- List open issues: `gh issue list --repo ibrahimashraf/MY_PROJECT`
- Read one issue: `gh issue view <number> --repo ibrahimashraf/MY_PROJECT`

## Linking
- Finishing PR: `Closes #<number>` in PR body (closes on merge)
- Partial PR: `Relates to #<number>` in PR body (references without closing)
- Close by hand: `gh issue close <number> --repo ibrahimashraf/MY_PROJECT`
