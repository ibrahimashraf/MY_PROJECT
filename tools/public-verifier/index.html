Public Verifier

Sovereign offline verifier. Zero backend calls, no network, no DB.

1. Envelope Ed25519 signature

Paste envelope JSON or open with #sig=<base64url>&did=<did>&payload=<b64url>.





2. RFC 6962 Merkle leaf inclusion


Paste #leaf=<hash>&root=<root>&index=<i>&size=<n>&proof=<p1,p2,...>
(all hashes hex). Optional &data=<b64url> recomputes the leaf hash from the appended leaf bytes and must match leaf.
